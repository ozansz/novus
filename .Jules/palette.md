## 2024-05-22 - Pressable over TouchableOpacity on Web **Learning:** `TouchableOpacity` lacks native web accessibility roles and hover state support, making the UI feel static and less accessible on web. `Pressable` allows for easy implementation of hover states (via style function) and proper ARIA roles. **Action:** Replace `TouchableOpacity` with `Pressable` in interactive components and add hover styles for better web UX.
